# Game Themes — Full Catalog

Full catalog of proposed themes per game. Themes marked **[LAUNCH]**
ship in the first shop wave; everything else is a candidate for later
drops. Cross-referenced from `docs/coins-and-shop-plan.md`.

Every theme is a **visual reskin only** — same rules, same engine, same
gameplay. Content-varied products live under Editions (see the
per-edition docs) or Packs (library rows).

## Design rules across every theme

- Same price band per game (400 coins default; premium art can bump to
  500)
- Free default theme always exists per game (grandfathered — never
  removed)
- All new themes ship priced from day one
- Themes must remain legible in both light and dark app themes
- Colorblind-friendly — themes cannot rely on colors that clash with
  gameplay-critical color signaling (e.g. a red-heavy Sudoku theme
  cannot swallow the red validation tint)
- No trademarked motifs, brand logos, or licensed characters

## Whot

Card-back designs, deck art, table felt.

- **[LAUNCH] Neon Whot** — dark background, glowing deck, cyberpunk
  palette. Reads modern, appeals to younger players.
- **[LAUNCH] Naija Whot** — Ankara / Adire textile motifs on the card
  backs, warm-toned deck. Highest cultural resonance in the largest
  Whot-playing market.
- **Wooden Whot** — rustic tactile deck on a wood-grain table. Family
  living-room vibe.
- **Casino Whot** — green felt table, gold accents, glossy card
  finish. "Serious" vibe.
- **Retro Whot** — 70s color palette (avocado, mustard, brown), chunky
  typography.
- **Kids Whot** — bright primary colors, playful icons, oversized
  numbers.
- **Christmas Whot** — seasonal drop; red/green/gold card backs, snow
  motif on table felt. Ships alongside the Christmas edition wave.
- **Vintage Whot** — sepia tones, ornate borders, "pre-war" playing-
  card aesthetic.

## Cadence

- **Launch (Phase 3):** the 6 [LAUNCH]-tagged themes above (2 each for
  Whot, Ludo, Sudoku).
- **Post-launch monthly drops:** pick one game per drop, ship 1–2 new
  themes for it. Rotate through the catalog. Add a "New in shop"
  badge for the first two weeks.
- **Seasonal:** Christmas variants of the popular games (Whot, Ludo,
  Snake & Ladder, Match Up) drop together in early December alongside
  the Christmas edition.

## Adding a new theme (checklist)

- Confirm the game supports themes (see per-game section above)
- Design brief: 1 page — what the card back / board / palette looks
  like, in dark and light mode
- Trademark check: no branded motifs, licensed characters, or
  trademarked names
- Contrast check: does the theme let gameplay-critical color signals
  still read?
- Price: default 400 coins; bump to 500 only if art is genuinely
  premium
- Insert `game_themes` row with `slug`, `game_type`, `name`, `art`
  JSONB, `price_coins`
- Add to the game's theme picker in the host lobby
- Ship
